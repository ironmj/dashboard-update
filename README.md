# dashboard-update

讀取兩份 Excel，自動產生離線單頁 HTML 儀表板（暗色主題、純 CSS/JS、無外部依賴）。

## 功能

- 分頁一「鐵皮採購額度」：各採購案的總採購量、使用量、剩餘可使用量、剩餘可使用天數
- 分頁二「護角分條庫存」：分條請購案進度、內外護角庫存與可使用天數
- 只讀取 Excel 中「可見」的欄、列、工作表，隱藏內容一律略過
- 不推算新數據，只做一致性檢查並印出檢查報告

## 輸入檔案

| 檔案 | 檔名需包含 | 格式 |
|---|---|---|
| 鐵皮採購額度 | `鐵皮採購剩餘額度`（或含 `鐵皮`） | .xlsx |
| 護角分條庫存 | `護角` 與 `分條`（或含 `護角`） | .xls / .xlsx |

資料夾內若有多個符合的檔案，採用最新修改者，並在檢查報告提醒。

## Excel 版面辨識規則

- 鐵皮採購區塊：標題列含「更新日期」，以「合計」列結尾
- 分條請購案：標題以「分條請購案」結尾
- 護角庫存：標題含「護角」與「截至」

## 程式設定

程式最上方三個變數：

```python
INPUT_DIR = "輸入資料夾路徑"
OUTPUT_DIR = "輸出資料夾路徑"
OUTPUT_NAME = "鐵皮額度儀表板.html"
```

## 執行流程

1. `find_file`：在輸入資料夾找出兩份 Excel
2. `read_xlsx` / `read_xls`：讀取可見儲存格，略過隱藏欄、列與工作表，遇到錯誤值（如 `#REF!`）記入警告
3. `parse_quota`：解析鐵皮採購區塊
4. `parse_slit`：解析分條請購案與內外護角庫存
5. 將資料轉成 JSON，填入 HTML 範本（`TEMPLATE`）
6. 輸出 `鐵皮額度儀表板_日期.html`，日期優先取自護角庫存的「截至」日期，其次為檔名中的 8 碼日期，最後為當天日期
7. 印出區塊數量與檢查報告

## 輸出內容

- 採購案：使用量／剩餘量堆疊長條圖、剩餘可使用天數、明細表
- 分條請購案：剩餘天數、送回／未送回／剩餘量長條圖
- 護角庫存：廠內與代工庫存長條圖、可使用天數、平均用量、明細表
- 圖表滑鼠移上去會顯示數值
- 頁尾顯示資料來源檔名

## 檢查報告

- 總採購量 ≠ 使用量 ＋ 剩餘量
- 合計列與各分項加總不符
- 分條請購案的量與總採購量不符
- 護角總庫存 ≠ 各欄庫存加總
- 可見區出現錯誤值
- 找不到採購案、分條請購案、內護角或外護角區塊
- 資料夾內有多個符合條件的檔案

檢查報告只提醒，不會修改任何數值。
